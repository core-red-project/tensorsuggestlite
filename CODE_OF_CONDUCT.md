# Code of Conduct

## Purpose

TensorSuggestLite is maintained by CoreRed Project as an experimental tool for the community. This Code of Conduct establishes expectations for participation to ensure a professional and productive environment.

## Scope

This Code of Conduct applies to:

- GitHub repository interactions (issues, pull requests, discussions)
- Communication channels related to the project
- Representation of the project in public spaces
- Direct communication with maintainers regarding the project

## Expected Behavior

Participants are expected to:

- Communicate professionally and respectfully
- Focus on technical merit and project goals
- Provide constructive feedback
- Respect differing viewpoints and experiences
- Accept responsibility for mistakes and learn from them
- Prioritize the project's stability and long-term viability

## Unacceptable Behavior

The following are not tolerated:

- Personal attacks, insults, or derogatory comments
- Harassment of any kind, public or private
- Publishing private information without consent
- Spamming, trolling, or deliberate disruption
- Promoting commercial interests without prior approval
- Deliberately introducing vulnerabilities or malicious code

## Technical Conduct

Contributors must:

- Submit honest work and accurate information
- Not plagiarize code without proper attribution
- Respect intellectual property and licensing terms
- Report security vulnerabilities responsibly (see SECURITY.md)

## Enforcement

### Reporting

Violations should be reported to:
- **Primary**: houjou.sxnnyside@sxnnysideproject.com
- **Alternate**: support.sxnnyside@sxnnysideproject.com

Reports are reviewed by CoreRed Project maintainers. Confidentiality is maintained to the extent possible.

### Actions

Maintainers may take the following actions for violations:

1. **Warning**: Private communication explaining the violation
2. **Temporary Restriction**: Time-limited ban from project interactions
3. **Permanent Ban**: Permanent removal from all project spaces

Decisions are made at the maintainers' discretion based on severity and history. Repeat violations result in escalated consequences.

### Appeals

Appeals may be submitted to: legal.sxnnyside@sxnnysideproject.com

Appeals are reviewed within 30 days. Decisions are final.

## Attribution

This Code of Conduct is adapted from established open source community standards and tailored for TensorSuggestLite's experimental status and governance model.

## Modifications

CoreRed Project reserves the right to modify this Code of Conduct at any time. Changes take effect immediately upon publication in the repository.
